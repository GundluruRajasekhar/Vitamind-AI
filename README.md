# Vitamind-AI
Calculators: a BMI calculator and a blood pressure analyser (normal, elevated, stage 1, stage 2, crisis, low). Rule engine: if-then rules like the ones you listed (heart rate above 100, BP of 140/90 or more, BMI of 30 or more, a medicine missed for more than 3 days). Each rule has a severity and a recommendation, and together they give a 0–100 risk
